# 🎬 AI Urdu Video Creator

Create Urdu voiceovers and promotional video content using your mobile phone.

## ✨ Features
- Convert text into Urdu speech
- Generate AI voiceovers using Edge TTS
- Create promotional video content
- Simple and mobile-friendly interface
- Built with Python and Streamlit

## 🛠️ Technologies
- Python
- Streamlit
- Edge TTS
- Requests
- BeautifulSoup4

## 🚀 How to Run
Install the required packages:

pip install streamlit edge-tts requests beautifulsoup4

Run the app:

streamlit run app.py

Make Urdu video creation easier and more accessible.
